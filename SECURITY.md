# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of JarSentinel and the integrity of bytecode security scanning seriously.

If you believe you have found a security vulnerability (such as a parser crash, denial-of-service, or remote execution vector triggered by malformed bytecode), please do **NOT** open a public GitHub issue.

Instead, please send an email with full reproduction steps to the repository maintainers or report it privately through GitHub Security Advisories.

### Response SLA
- **Initial Acknowledgement**: within 48 hours
- **Triage & Patch Estimate**: within 7 days
- **Advisory & Release**: upon patch availability
